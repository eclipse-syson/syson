== Register

First report:: The date the problem was first reported publicly.
Area:: The part of SysON affected by the problem.
Symptom:: What users observe when the problem occurs.
Affected SysON:: The SysON versions in which the evidence shows the problem was present. `Unknown` means the affected version still needs checking.
Status:: `Confirmed` means the evidence shows the behavior worked before it degraded in a published version. `To verify` means more evidence is needed to tell whether the problem was a regression.
Report and evidence:: Links to the public report and the evidence used to assess the case.
First published fix:: The earliest published SysON version verified to contain the fix, including patch releases. `Unknown` means a possible fix has been identified and the review still needs to check which published SysON version, if any, contains it. `None verified` means the review has found no candidate for a published fix.
Regression test:: A link to a test that covers the reported scenario. `Not identified` means a matching test has yet to be found.
