= 2026.12.0

== Key highlights

== New features

* For application developers:

** New metamodel query services expose nested feature paths from a `Type` context, including inherited features and effective redefinitions.
Applications can filter branches and results, and consume paths lazily through a stream with bounded cycle traversal.

== Bug fixes

* In SysML models:

** Redefined features now replace their originals in the features available on a `Definition` or `Usage`, including when a redefinition changes the feature name or is inherited through multiple specialization paths.
