= 2026.12.0

== Key highlights

* Standard diagrams are now faster and more responsive.

== New features

* In the Explorer, `Collapse all` collapses an item and its descendants.

* In diagrams:

** A new _Redefine a nested feature_ tool is available in the _Structure_ section of diagram palettes for `Usage` and `Definition` graphical nodes.
This initial implementation opens a selection dialog listing configurable feature paths.
Confirming a selection closes the dialog without modifying the model.
Actual feature redefinition will be added in a subsequent change.

* For application developers:

** New metamodel query services expose nested feature paths from a `Type` context, including inherited features and effective redefinitions.
Applications can filter branches and results, and consume paths lazily through a stream with bounded cycle traversal.
Collecting paths into a list requires an explicit maximum number of results.
A reusable traversal predicate excludes features declared in standard libraries while retaining model and business library features.
Chain selection filters receive the root context and complete paths, with a reusable predicate to exclude paths that need no further local redefinition.

== Bug fixes

* In SysML models:

** Redefined features now replace their originals in the features available on a `Definition` or `Usage`, including when a redefinition changes the feature name or is inherited through multiple specialization paths.

== Improvements

* In diagrams:

** Creating elements in standard diagrams is faster, especially when inherited elements are displayed.
