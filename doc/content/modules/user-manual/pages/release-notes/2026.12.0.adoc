= 2026.12.0

== Key highlights

* A new parser and serializer improve SysML v2 import and export, making it easier to bring models into SysON and share them as text.
* Standard diagrams are now faster and more responsive.

== New features

* In the Explorer, `Collapse all` collapses an item and its descendants.

* In diagrams:

** A new _Redefine a nested feature_ tool is available in the _Structure_ section of diagram palettes for `Usage` and `Definition` graphical nodes.
This initial implementation opens a selection dialog listing configurable feature paths.
Confirming a selection closes the dialog without modifying the model.
Actual feature redefinition will be added in a subsequent change.

* For application developers:

** New metamodel query services expose nested feature paths from a `Type` context, including inherited features and effective redefinitions.
Applications can filter branches and results, and consume paths lazily through a stream with bounded cycle traversal.
Collecting paths into a list requires an explicit maximum number of results.
A reusable traversal predicate excludes features declared in standard libraries while retaining model and business library features.
Chain selection filters receive the root context and complete paths, with a reusable predicate to exclude paths that need no further local redefinition.

** The standalone `syson-sysml-serializer` module is included in `syson-starter`.
It writes OMG SysML models as normalized text, round-trip text that preserves parser-recorded syntax, or standalone HTML with syntax highlighting.
Use `SysONTextSerializer` for SysON model elements in place of the deprecated `SysMLElementSerializer`.
See the xref:developer-guide:textual-sysml.adoc[Textual SysML developer guide].

** Applications can now create local redefinitions along a selected feature path before configuring its usages.

== Bug fixes

* In SysML models:

** Redefined features now replace their originals in the features available on a `Definition` or `Usage`, including when a redefinition changes the feature name or is inherited through multiple specialization paths.

** Actions and other behaviors now correctly include inherited parameters.
Unnamed parameter redefinitions inherit the original parameter's name, and replaced parameters are no longer listed alongside their replacements.
When an action parameter explicitly redefines one parent's input, SysON also recognizes the corresponding input from another parent.
Return parameters match independently of input order.

* In diagrams:

** A _Requirement_ or _Concern_ graphical node shows each inherited _Stakeholder_ once, with the `^` marker.
** A nesting graphical edge is displayed only for a locally owned _Stakeholder_, preventing an inherited _Stakeholder_ from being shown as locally contained.
** Undoing the `Add existing elements` tool doesn't remove graphical nodes that were present before applying the tool anymore.

* In validation:

** Internal errors while checking a constraint no longer appear as model violations in the Validation view.
Other checks continue to run so independently detected model problems remain visible.

** When a _Redefinition_ relationship is missing either required feature, the Validation view now reports one error asking users to complete the relationship.
Checks that depend on these features are deferred to avoid secondary diagnostics, while independent checks continue.
The error disappears and dependent checks resume once both features are set.

== Improvements

* In diagrams:

** Creating elements in standard diagrams is faster, especially when inherited elements are displayed.

* In export:

** xref:user-manual:features/import-export-textual.adoc[Textual SysML downloads] now use a new serializer to produce text.
Expression text, diagram labels and direct-edit text, and feedback messages use this new serializer.
