= Other views

The following views are planned for {product}:

* _Sequence View_,
* _Geometry View_,
* _Grid View_,
* _Browser View_.

To understand the purpose of each view, see the xref:user-manual:features/sysmlv2-overview.adoc[{sysmlv2} in practice] section of the user manual.

Wait until the next release to enjoy these views.

The _Case view_ is not available in {product} because its concepts and features are available in the _General View_.

Feel free to xref:ROOT:help.adoc[contact us] for more details.
