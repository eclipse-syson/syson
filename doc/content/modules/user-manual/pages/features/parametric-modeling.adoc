= Parametric modeling and constraints

Unlike {sysmlv1}, {sysmlv2} uses ports to define connection points on parts and Interconnection View diagrams to manage part input parameters.

In an {iv} diagram, users can create ports with or without a defined direction from a part's contextual palette.
To represent data flow between ports, users can create either an `InterfaceUsage` or a `BindingConnector` usage when connecting two ports.
These data flows visually represent how parameter values relate to each other, allowing their propagation through the model.
